# Sprint 0: Cat Collects Coins

This is a 2D game created using C# and Monogame. The player collects coins as a cat and increases the score. 

### Controls
W / A / S / D or Arrow Keys: Move the cat
Left Mouse Button: Cat animation
Escape: Exit the game
